# Install UserLeap

Installing the SDK is a simple procedure that allows you to send in-product micro surveys to your userbase. Installation is **required** and can be done via a host of methods - all depending on your platform. 

Continue reading for more information around UserLeap installation

## **Platforms**

There are four ways for your customer to experience UserLeap and these are described from a terminology perspective as Platforms. Two of the UserLeap platforms only perform if in your product or web pages, you've installed the UserLeap software described as Web or Mobile SDKs.  

* **Installation Required**
  * Web Applications 
  * Mobile Applications
* **Installation Not Required**, but suggested 
  * Email 
  * Link Based

_Documentation for installation lives_ [_**here**_](http://docs.userleap.com/installation)_**,** but see below for a brief summary:_

## **Web SDK**

For Web \(both desktop browsers and mobile web browsers\), you have the option to either install the UserLeap [J**avaScript SDK**](http://docs.userleap.com/installation/javascript-sdk) ****or use ****[**Google Tag Manager**](http://docs.userleap.com/installation/google-tag-manager-new) ****\(GTM\). UserLeap has a custom template in the GTM Library. 

Platform installations typically take **30 minutes** and may require someone from the development team to perform the task. For quicker turn arounds on the install, many UserLeap customers get started with Google Tag Manager.  If you’re unsure of whom to reach out to internally within your company, we find that most often, installation decisions reside with the Product or Engineering department.

## **Mobile SDK**

Similar to the install requirement for Web \(see above\), you’ll need to first install the SDK before going live with UserLeap. We support both [**iOS**](https://docs.userleap.com/installation/ios-sdk) ****and [**Android**](https://docs.userleap.com/installation/android-sdk)**.**

UserLeap supports [**React Native**](../installation/mobile-sdks/react-native-module.md) for iOS and Android

## **Setting User Properties**

UserLeap persists unique user identifiers in local storage \(known as visitorids\). Adding your own userids/emails to UserLeap provides a better experience in the platform and will allow you to identify survey respondents.

For a web install, please read ****[**this**](https://docs.userleap.com/installation/javascript-sdk#user-identity) \(JavaScript SDK\) or [**this**](https://docs.userleap.com/installation/google-tag-manager-new/user-ids) \(Google Tag Manager\) for ideas on how to send UserLeap userid properties. Identifying users in a mobile application can be found [**here**](https://docs.userleap.com/installation/ios-sdk#user-identity) \(iOS\) or [**here**](https://docs.userleap.com/installation/android-sdk#user-identity) ****\(Android\).

You can check whether or not user properties have been set correctly on the people [**page**](https://app.userleap.com/visitors/all).
