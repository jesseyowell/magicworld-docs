  There are various times when you'll want to manage a voucher's accessibility.
  This can be done by two API methods for managing the voucher state - *enable*
  and *disable*.  

  ___

  The method sets the voucher state to **active**. The voucher can be redeemed -
  only if the redemption occurs after the start date and the voucher is not
  expired.
