title: Create Voucher
excerpt: >-
  Create a standalone voucher. You can choose to create a `GIFT_VOUCHER`, a
  `DISCOUNT_VOUCHER`, or a `LOYALTY_CARD`. The code path parameter can use all
  letters of the English alphabet, Arabic numerals and special characters.  


  When you create a new voucher, you can specify a type to create it.

  Creating a new voucher will create a new stand alone voucher if no `campaign`
  name or `campaign_id` is provided. In case of the loyalty card, a campaign
  name is required.
